SHIORI FOR WINDOWS
==================

Shiori is a private anime and manga hub that runs on your own computer.

FIRST LAUNCH
1. Extract the whole zip to a folder you keep.
2. Double-click Shiori.exe. Shiori is not code-signed yet, so Windows may show
   "Windows protected your PC". Click "More info", then "Run anyway".
3. Your browser opens a local setup page. Choose a password of at least 20 characters.
4. Shiori opens in a new browser tab as soon as it is ready (http://127.0.0.1:43000)
   and stays available from the tray.
5. A "Shiori" shortcut is placed on your Desktop and in the Start Menu automatically.

LATER LAUNCHES
Double-click the "Shiori" icon on your Desktop (or search "Shiori" in the Start
Menu). If Shiori is already running, the same click just opens it in the browser.
Keep the extracted folder where it is; the shortcut points to Shiori.exe inside it.

YOUR DATA
Settings, history and the database live in:
%APPDATA%\Shiori

Anime downloads use the library folder you choose inside Shiori. Check the free space on that drive before starting a season download.

STOPPING SHIORI
Right-click the Shiori tray icon and choose Quit Shiori.

SECURITY
Shiori listens on this computer only by default and enables strict mode during setup. Do not forward port 43000 on your router. Use Tailscale if you want to reach your copy from another device.

SYSTEM REQUIREMENTS
Windows 10 or 11, 64-bit.
