Questions people ask.

Does Shiori host anime?

No. It hosts nothing. It runs on your own computer and fetches from sources you choose to install.

Do I need an account?

No. You set your own password for your own copy. Connecting AniList is optional and only adds progress tracking.

Can I use someone else's Shiori?

You should not. Every copy belongs to the person who runs it. Install your own: it takes about five minutes.

Which systems does it run on?

The release is built for Windows. macOS and Linux users can build it from source; the docs have the commands.

Where is the art from?

Fan art and stills collected by the maintainer as mood pieces. Every character and artwork belongs to its creator.
